Selecione um modelo para ver o limite configurado.

Orientação de registro

  1. Selecione o código do modelo cadastrado.
  2. Confirme o material perdido e informe a quantidade.
  3. O custo é calculado pelo preço unitário cadastrado.
  4. Cada registro representa uma ocorrência para contagem do limite.
  5. Ao atingir o limite configurado, o sistema exibe um alerta.
Para comparar custos corretamente, mantenha atualizados os preços unitários e a unidade de medida dos materiais.

Modelos e limites

Cadastre e edite código, numeração, material padrão e limite de alertas por modelo.

Cadastrar modelo

Cadastre as numerações no menu Numerações. Marque todas as que o modelo utiliza.

Como o limite funciona

O contador considera ocorrências registradas para cada modelo dentro da janela de contagem configurada no protótipo.

!
Alerta de limite

Quando a contagem chega ao limite do modelo (por exemplo, 3 ocorrências), o sistema sinaliza no dashboard e na área de histórico.

Nesta versão, a contagem é acumulada no histórico completo. A regra de reinício por turno/período pode ser definida na próxima etapa.

Materiais e custos

Cadastre materiais, unidades e preços para calcular o custo estimado de cada perda.

Cadastrar material

Cálculo financeiro

Custo estimado = quantidade de peças perdidas × custo estimado por peça.

ⓘ
Atenção às unidades

O custo cadastrado deve representar o valor estimado do material perdido por peça. Ajuste esse valor conforme o critério de custo usado pela fábrica.

O custo é uma estimativa baseada no preço cadastrado, não substitui o custo contábil/ERP.

Usuários e níveis de acesso

Cadastre colaboradores e gerencie o acesso ao sistema com Supabase Auth.

ⓘ
Usuários reais do Supabase

Somente administradores podem cadastrar contas. Cada colaborador entra com e-mail e senha. Desative o perfil para bloquear seu acesso ao PU Control.

Cadastrar usuário

Como cadastrar usuários

  1. Informe um nome de usuário, e-mail válido e nome completo.
  2. Defina uma senha inicial com pelo menos 8 caracteres e compartilhe-a com o colaborador por um canal seguro.
  3. Escolha o perfil: Operador, Consulta ou Administrador.
  4. Use o status Inativo para bloquear o acesso sem apagar o histórico.
  5. O colaborador acessa com o e-mail e a senha cadastrados.

As senhas são gerenciadas pelo Supabase Auth e não ficam armazenadas na aplicação. Para criar contas, publique a Edge Function incluída neste pacote.
